# 亚马逊商品图制作模板

从本次请求所在环节开始。Codex 先从现有资料代填；只向运营补问会改变当前图片的缺项。方括号是填写说明，实际交付时替换成内容。以下是给人读的工作底稿，文件版本与任务状态以项目清单为准。

## 1. 产品档案与素材目录

```markdown
### [产品名] · [SKU / 变体]

销售站点与语言｜[站点、上图语言]
本次委托｜[策划 / 提示词 / 出样 / 修改 / 整套交付；已有运营图序或自主策划]
购买场景｜[谁在什么场景用，购买前最需要确认什么]

| 产品事实或对外主张 | 内容与适用变体 | 依据（实拍、规格书、运营资料及具体位置） | 已核实 / 预估 / 待核实 |
|---|---|---|---|
| [实售颜色、结构、材质、尺寸、功能等] | [数值、单位、适用条件] | [文件名及页、行或照片角度] | [状态] |

| 素材文件及位置 | 对应 SKU、角度或用途 | 可作生成输入 / 仅供分析 / 待确认 | 限制 |
|---|---|---|---|
| [具体文件] | [实拍 / 可编辑底图 / 竞品参考 / 反馈截图] | [用途权限] | [例如只参考光线] |

容易画错的地方｜[外轮廓、数量、连接方式、真实色泽；列出核对照片]
资料冲突或缺口｜[不同来源分别怎么说、影响哪张图；可先完成哪些工作]
```

## 2. 图序与单图制作卡

```markdown
### [SKU] 本次图序

| 图号 / 用途 | 买家的问题 | 用什么画面证明 | 实拍依据 | 文案或规格依据 |
|---|---|---|---|---|
| [沿用运营编号] | [一个具体疑问] | [产品动作、结构、尺寸参照或细节] | [文件名] | [目标站点要求或原始资料] |

### [图号、变体、版本] 制作卡

目标｜[站点、MAIN / 商品副图 / A+具体模块 / 拍摄素材；原生像素要求、交付画幅、像素、格式；两种尺寸分别填写]
来源｜[逐个列出本次实际送入图片工具的文件；注明哪张是底图、哪张校准外观]
画面｜[主体角度和比例、动作或摆放、背景、光线、文字留白区]
上图文案｜[逐字终稿、语言、来源；无需上字时填“无”]
给图片工具的完整指令｜以[文件 A]为[底图或产品依据]，使用[文件 B]核对[细节]。本图让买家看清[目的]。把[主体]置于[位置、角度、场景、光线]，保留[本品可辨认的结构、数量、材质、颜色]。[如为编辑，写明只改哪一处、其余区域要保留什么。] [需要直接上图的准确文案，或明确为后期排字预留位置。] 输出[画幅与用途]。避免[最可能画错的具体细节]。
验收｜[逐项写可看见或可测量的判据；标注对照实拍]
```

MAIN 先核对该站点与类目的商品展示、背景及销售变体要求。商品副图按购买疑问选择场景、对比或尺寸说明。A+ 指定所选模块和移动端适配要求，使用实际模板核对裁切。拍摄角度可被多张成品复用，按实拍素材与页面成品分别计数。

整套制作时复用本 SKU 的事实与视觉方向；每张只附本图需要且获准用于生成的参考素材。新风格或易失真结构先选一张验证；已经有选定样式时可直接处理待做图。局部返工只列受影响图号，已完成且无变更的图直接沿用。

## 3. 修改与视觉核对

```markdown
### [SKU / 图号] · [原版本 → 新版本]

反馈原话与位置｜[原话、日期或来源]
指定底图｜[可打开的文件名和版本]
本次改动｜[对象、区域、期望效果；或仅调整交付规格]
保留项｜[产品、构图、背景、文字、尺寸或其他未改区域]
本次输入与输出｜[实际输入文件；新版文件名；旧文件保留位置]

| 对照项 | 参照对象 | 实际观察 | 通过 / 需修改 / 未核实 |
|---|---|---|---|
| 指定改动 | [反馈与底图] | [改动位置、有无达到目的] | [结果] |
| 保留项与实物细节 | [底图、同角度实拍] | [逐项可见差异，包含意外漂移] | [结果] |
| 文案与交付规格 | [文案原件、制作卡或模块模板] | [实际文字、像素、格式及裁切] | [结果] |

下一步｜[待运营选择的候选文件、需要再改的部位或待核实的问题]
```

仅改规格时用确定性的适配方式，并查看成品是否变形、切断部件或改变文字留白。涉及生成编辑时另存新版本，保留前后图。需要原生分辨率时，开工前确认工具能否交付；规格核对记录原生结果和导出方式。检验局改时，先圈出允许编辑的位置，再检查其余产品区域的漂移并与实物对照。

## 4. 运营交付与接手

```markdown
### [SKU / 用途 / 本次交付范围]

运营委托｜[本次要解决的问题、指定图号或版本]
本轮结果｜[新增多少、修订多少、哪些沿用现有文件；欠缺什么]

| 图号 / 变体 | 用途 | 实际文件、版本、像素与格式 | 文件检查 / 视觉检查 | 运营选择及依据 |
|---|---|---|---|---|
| [编号] | [MAIN / 副图 / A+模块等] | [经实际打开的文件] | [分别记录] | [待选 / 已选 / 退回修改，附对应反馈] |

接手位置｜[最近一次选定的底图、关联制作卡、待办图号与下一步]
```

交付前从清单逐个打开本次要交的文件，核对路径、文件数、像素、格式、变体、上图文案和目标用途。候选图、运营选定与平台审核分别记录；暂时无法核实的项目随对应图号交接。
